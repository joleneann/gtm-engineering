# Changelog

Every row is a change made to the build's stated design, with the phrase it withdrew. A withdrawn
phrase must never reappear in `docs/`, `CLAUDE.md` or `README.md`; `scripts/00_doc_check.py`
reads this table and enforces that.

Rows 1 to 44 were written while this table lived at the top of `docs/source_of_truth.md`. That
document was rewritten whole on 2026-09-05 and the table moved here, so a row may describe a
sentence that no longer exists anywhere. That is the point: the row is the record that the phrase
was withdrawn, and the check is what stops it coming back.
